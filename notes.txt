Variables: let, const

Conditions: if, else, switch
Loops: for, while, for...of
Functions:
normal functions
arrow functions
parameters and return
Arrays:
push, pop, shift, unshift
map, filter, reduce, find, some, every
Objects:
object creation
accessing properties
destructuring
nested objects

Phase 3: Modern JavaScript

This is the real full-stack JS foundation.

Learn:

Template literals

`Hello ${name}`

Destructuring

const { name, age } = user;

Spread/rest operator

const newArr = [...arr, 4];

Optional chaining

user?.profile?.image

Modules

export default App;
import App from "./App";

Higher-order functions

users.map(user => user.name)
Callback functions

Error handling

try {
  // code
} catch (error) {
  console.log(error);
}
